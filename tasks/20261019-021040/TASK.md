# Add Color Setting

- STATUS: OPEN
- PRIORITY: 50
- TAGS: Feature

A little thing that does a lot. Right now, the background is PURE WHITE, #FFFFFF, RGB(255, 255, 255), The color of the sun, and that's what it looks like. Really, really bright. I know there are some weirdos out there that really like light mode on everything, and I am not one of them, so I am thinking about having an option where you can set the foreground and background color of things, so instead of blinding white background, you could have a nice #181818 background with off-white text.
