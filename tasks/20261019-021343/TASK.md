# Add Lua to replace Tcl 6.x/7.x

- STATUS: OPEN
- PRIORITY: 65
- TAGS: Modernization

Instead of Tcl 6/7, I'd like to replace it with Lua, since it's embedable, and more widespread than Tcl. Another reason is that it has very good support on older hardware/software, with an example being me being able to run Lua 5.5.0 on a Intel 80386 with Debian 3.1 ( https://youtu.be/Z_siROPetmg?t=474 ).

It should support all the original things that Tcl used to support, as well as having things for coloring text, such as for things like code coloring.
